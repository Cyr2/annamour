# Logo Annamour

Direction retenue : **« le sourire »**. Deux points (toi et l'autre) reliés par le fil rouge, qui passe sous le mot et remonte vers le second point.

Texte en Fredoka 600, vectorisé (aucune police requise). Couleurs de la palette « Nuit douce » (voir `CLAUDE.md`).

| Fichier | Usage |
|---|---|
| `annamour-logo.svg` | Logo sur fond sombre (fond transparent, texte lait) |
| `annamour-logo-nuit.svg` | Même logo avec son fond nuit inclus |
| `annamour-logo-clair.svg` | Logo sur fond clair (texte encre, fil rose plus soutenu) |
| `annamour-logo-mono-lait.svg` / `-mono-nuit.svg` | Une seule couleur, pour les supports imprimés, les tampons et les filigranes |
| `annamour-symbole.svg` / `-clair.svg` | Le symbole seul (deux points et le fil) |

Les icônes de l'application sont dans `apps/web/public/` :

- `icon.svg` : tuile arrondie, sert aussi de favicon.
- `icon-maskable.svg` : symbole dans la zone sûre de 80 %.
- PNG : 192 px, 512 px, maskable 512 px et `apple-touch-icon` 180 px.

Couleurs des deux points : rose pêche `#FF8C9E` et rose plus clair `#FFC2CC`. Sur fond clair, ces teintes deviennent `#E8546E` et `#F28A9C`.
